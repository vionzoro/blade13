# BLADE:13 — Q 版独角兽英雄、彩虹技能与快节奏难度设计

日期：2026-08-14  
赛事：js13kGames 2026  
主题：Unicorns and Rainbows  
包体上限：13,312 字节（13 KiB）

## 1. 目标

在不改变输入方式、升级系统、碰撞规则和核心割草循环的前提下完成三项改造：

- 将玩家英雄重绘为一只双腿站立的 Q 版独角兽；
- 将三刀表现改为单刀，并让普通挥刀、BLINK 与 PRISM BREAK 都带有分层彩虹特效；
- 加快敌人刷新、威胁升级和首领到场节奏，以密度与敌人组合提升难度。

完成后，玩家应在开局第一眼识别出 `🦄` 式侧面独角兽轮廓，同时保留原角色的黄夹克、黑风衣、品红围巾、赛博义体和忍者动作身份。

## 2. 已确认的角色方向

### 2.1 整体比例

英雄不再是“人类身体换马头”，而是完整的双足 Q 版独角兽：

- 头身比约为 1:1.6，兼顾可爱与战斗动作；
- 身体保持直立，前肢承担手臂功能，后肢以短马蹄站立和奔跑；
- 使用现有角色坐标、朝向、跑动摆动和受击闪烁，不扩大碰撞半径；
- 继续保留黄夹克、深色风衣下摆、品红围巾、铬合金肢体和前倾姿态。

### 2.2 `🦄` 式头部

头部必须使用表情符号式侧面轮廓，而不是正面人形马脸：

- 白色侧面马头，口鼻明显向前伸出；
- 单个大眼睛和友好表情；
- 金黄色长角从额头向前上方伸出；
- 后脑使用粉、紫、蓝、青为主的彩虹鬃毛；
- 整个英雄继续由现有 `fx` 水平翻转，因此侧脸会随移动朝向自动转向；
- 删除人脸、红色尖发、眼部护目条、伤疤、神经接口和爆发头巾。

### 2.3 单刀

- 删除嘴衔刀和副刀；
- 站立与奔跑时只绘制一把主手逆手刀；
- 自动攻击只绘制一把挥砍刀和一条主要弧线；
- 删除三刀并行弧线、三次主刀调用和额外分身刀；
- 伤害范围、攻击速度、伤害次数与命中判定保持现有逻辑，不因视觉上只剩一刀而削弱玩家。

## 3. 彩虹技能语言

所有主动战斗动作使用同一份现有 `RAINBOW` 七色表，不新增图片、渐变资源或状态字段。

### 3.1 普通挥刀

- 主手刀刃始终随时间轮换七色，不再只在 PRISM BREAK 中变彩色；
- 普通斩击弧使用短促、较细的彩虹分段或快速循环颜色；
- 保留白色刃芯与暗色刀身，确保敌群中仍能辨认刀的位置。

### 3.2 BLINK

- 起始冰蓝单色环替换为现有七色棱镜环；
- 突进路径上的角色残影始终使用彩虹边缘；
- 交叉斩继续沿用现有两道命中特效，但颜色改为七色；
- 位移、无敌时间、目标数量和冷却不变。

### 3.3 PRISM BREAK

- 激活环替换为现有七色棱镜环；
- 爆发持续期间继续使用全强度七色刀光、残影、击杀粒子和冲击环；
- 普通攻击、BLINK 与大招按照“轻量—醒目—全强度”逐级增加视觉密度；
- 受伤、低血量、敌方危险预警继续使用红色，不能被彩虹覆盖。

## 4. 节奏与难度

难度提升以更快的波次和更早的敌人组合为主，不额外提高基础伤害、基础生命或玩家受到的单次伤害。

### 4.1 开局与常规刷新

- 开局敌人数从 18 提高到 22；
- 基础刷新间隔从 `max(.14, .8 - T / 190)` 调整为 `max(.12, .68 - T / 170)`；
- 每批敌人数从 `2 + floor(T / 26)` 调整为 `2 + floor(T / 22)`；
- 保留现有敌人数上限与 LOD，避免性能失控。

### 4.2 威胁等级与首领

- 威胁等级间隔从 28 秒缩短到 22 秒；
- 首只 BLACK UNICORN 从 40 秒提前到 32 秒；
- 后续首领间隔从 32 秒缩短到 28 秒；
- 涌潮平方增长、首领攻击方式和首领数值公式保持不变。

### 4.3 敌人解锁节奏

高阶敌人提前出现，但不改其单体数值：

- 疾行者：6 秒 → 4 秒；
- 重装兽：15 秒 → 12 秒；
- 分裂体：24 秒 → 19 秒；
- 咒术体：36 秒 → 29 秒；
- 孵化巢：40 秒 → 32 秒；
- 引爆体：50 秒 → 40 秒。

该方案让 30 秒内出现更完整的敌人组合，并在约 32 秒进入第一次首领高峰。玩家升级、回血、BLINK 和 PRISM BREAK 的数值不变，难度来自更快的决策压力。

## 5. 代码边界

预计只修改以下现有文件：

- `src/00-core.js`：开局敌人数与首次首领时间；
- `src/20-game.js`：刷新、威胁、敌人解锁、后续首领和彩虹技能触发；
- `src/40-render.js`：斩击和残影的彩虹表现；
- `src/45-art.js`：完整 Q 版独角兽英雄和单刀绘制；
- 必要的现有验证脚本与交付文档。

不新增运行时模块，不改变模块加载顺序，不引入外部资源、网络请求、字体、图片或音频文件。

## 6. 体积策略

基线构建为 13,021 字节，距离 13,312 字节硬上限还有 291 字节。最终目标为不超过 13,100 字节，并保留硬上限余量。

主要策略是用新绘制直接替换旧绘制：

1. 删除人类头部、尖发、伤疤、护目条、神经接口、嘴衔刀和爆发头巾；
2. 删除副刀、三刀挥砍循环和重复刀刃调用；
3. 使用少量 Canvas 路径画出侧面马头、金角、大眼睛、彩虹鬃毛和马蹄；
4. 复用 `RAINBOW`、`prismRing`、`ghost`、现有角色翻转和现有动画变量；
5. 难度改造只替换常数，基本不增加压缩体积。

若构建超过 13,100 字节，按以下顺序缩减不影响游戏性的表现：

1. 合并独角兽头部与身体的重复描边路径；
2. 简化角色风衣装饰线、腿部冷光与非必要高光；
3. 删除旧角色专属但已不再适用的爆发装饰；
4. 减少普通攻击的重复光效层，仅保留彩虹刃口与主要斩击弧；
5. 最后才缩减非交互城市装饰或屏幕装饰。

不得为节省体积删除桌面/触摸输入、音频解锁、危险预警、敌人类型、升级卡、确定性随机、性能护栏、测试或核心打击反馈。

## 7. 性能与可读性

- 独角兽英雄继续使用 Canvas 路径即时绘制，不创建图像资源或每帧新纹理；
- 角色总路径数量应不高于旧三刀角色的绘制成本；
- 高敌人数下继续沿用现有 LOD；
- 普通攻击的彩虹层数少于大招，避免长期遮挡敌方子弹和地刺；
- 单刀视觉变化不改变攻击扇形和命中次数，避免视觉与操作手感分离；
- 角色碰撞半径保持原值，即使 Q 版头部视觉略宽也不扩大受击区域。

## 8. 验证计划

自动验证：

- `npm run verify` 全部通过；
- 两次构建哈希一致；
- 最终 ZIP 只包含根目录 `index.html`；
- ZIP 不超过 13,100 字节目标，且绝不超过 13,312 字节硬上限；
- 现有桌面、触摸、渲染、性能、种子扫描和打包冒烟测试继续通过；
- 更新任何依赖旧 40 秒首领或三刀绘制的断言。

浏览器人工验收：

- 静止、奔跑、左右转向、受击和 PRISM BREAK 中，英雄均为清晰的站立 Q 版独角兽；
- 头部呈 `🦄` 式侧脸，转向时正确翻转；
- 任何时刻只显示一把刀；
- 普通挥刀、BLINK 和 PRISM BREAK 都有可辨认且层级不同的彩虹特效；
- 首次威胁升级约在 22 秒、首次 BLACK UNICORN 约在 32 秒出现；
- 竖屏触摸按钮、桌面键盘、升级选择、危险预警和音频启动不回归。

## 9. 完成定义

只有在角色视觉、单刀、三类彩虹动作、快节奏难度、完整自动验证、浏览器验收和最终包体全部达标后才算完成。最终可提交 ZIP 需要同步到交付目录，并记录字节数与 SHA-256。
